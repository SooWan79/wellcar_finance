# 웰카오디오 매출/지출관리 시스템

기존 엑셀(웰그룹 경영관리 시스템, `2023년 경영관리.xlsm`) 기반 매출/지출 관리를
웹 시스템으로 옮긴 프로젝트입니다. 매일 매출·지출을 건별로 등록하면
일별 대시보드와 월별·분기별·연도별 통계 현황을 바로 확인할 수 있습니다.

## 주요 기능

- **매출관리** — 영업일자·매출유형·매출구분·차량제조사·제품모델·거래처·거래통화(KRW/CNY)·
  수량·단가·결제유형·세금계산서·계좌·적요 입력. 엑셀과 동일하게
  결제유형이 `카드`이거나 세금계산서 `Y`이면 부가세(매출액×10/110)와 순매출액이 자동 계산되고,
  CNY 거래는 `수량 × 단가 × 기준환율`로 원화 매출액이 자동 환산됩니다.
  등록 폼은 거래 정보 / 금액 / 결제·정산 / 메모 구역으로 나뉘고,
  오른쪽에서 최근 내역을 검색·수정·삭제할 수 있습니다.
- **지출관리** — 지출유형·거래품목(유형별 종속 드랍다운)·결제유형·거래처·적요 입력.
- **일별 대시보드** — 선택한 날짜의 매출/지출 내역 목록(수정·삭제 가능)과
  당일 매출·지출·순익 강조 카드(전일대비 증감), 당월 누계·부가세·현금/카드 매출·
  영업일수·일평균 매출 보조 지표, 최근 14일 추이 차트.
- **월별 현황** — 일자별 매출·지출 차트/테이블, 매출구분별·지출유형별 구성, 전월대비 증감.
- **분기별 현황** — 분기 내 월별 비교, 전분기대비 증감, 구성 분석.
- **연도별 현황** — 월별 손익 테이블(엑셀 '경영분석' 시트와 동일 구성), 전년대비 증감,
  매출구분별 구성과 거래처별 매출 TOP 10.
- **코드관리** — 매출유형/매출구분, 지출유형/거래품목, 결제유형, 계좌, 차량제조사,
  거래처, 통화 드랍다운 코드를 화면에서 직접 추가·삭제. 엑셀 '코드관리' 시트의
  코드가 기본값으로 들어 있습니다.
- **엑셀 가져오기(마이그레이션)** — 기존 경영관리 엑셀 파일(.xlsm/.xlsx)을 업로드하면
  '매출집계'·'지출집계' 형식 시트('영업일자'와 '매출액' 또는 '지출금액' 열이 있는 시트)의
  내역을 브라우저에서 직접 파싱해 DB로 이관합니다. 같은 파일을 다시 올려도 이미 등록된
  내역은 건너뛰며(멱등), 파일에 새로 등장하는 코드값은 코드관리에 자동 추가됩니다.
- **화면 모드 전환** — 상단의 토글 버튼으로 자동(OS 설정) → 라이트 → 다크 모드를
  전환할 수 있고, 선택은 브라우저에 저장되어 유지됩니다.

## 실행 방법

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 <http://localhost:8000> 접속. (포트 변경: `PORT=9000 python app.py`)

데이터는 프로젝트 폴더의 SQLite 파일 `wellcar.db`에 저장됩니다.
이 파일 하나만 백업하면 전체 데이터가 보존됩니다.

### 데모 데이터

통계 화면을 미리 확인하고 싶다면 샘플 데이터를 넣을 수 있습니다.

```bash
python seed_demo.py          # 최근 1년치 샘플 매출/지출 생성
python seed_demo.py --clear  # 모든 매출/지출 내역 삭제
```

## 구조

| 파일 | 역할 |
|---|---|
| `app.py` | Flask 서버 + SQLite 스키마/시드 + REST API (내역 CRUD, 통계, 코드관리) |
| `static/index.html` | 단일 페이지 UI (대시보드 / 매출·지출관리 / 통계 / 코드관리 / 엑셀 가져오기 탭) |
| `static/js/app.js` | 화면 로직 (폼 자동계산, 목록, 통계 렌더링) |
| `static/js/charts.js` | 경량 SVG 차트 (외부 라이브러리 없음, 오프라인 동작) |
| `static/js/xlsx_import.js` | 엑셀(.xlsx/.xlsm) 브라우저 파서 (ZIP+XML 직접 해석, 외부 라이브러리 없음) |
| `static/css/style.css` | 디자인 토큰 기반 스타일 (라이트/다크 모드) |
| `seed_demo.py` | 데모 데이터 생성/삭제 스크립트 |

## API 요약

- `GET/POST /api/incomes`, `PUT/DELETE /api/incomes/<id>` — 매출 내역
- `GET/POST /api/expenses`, `PUT/DELETE /api/expenses/<id>` — 지출 내역
  - 목록 필터: `?date=YYYY-MM-DD`, `?from=&to=`, `?q=검색어`
- `GET /api/stats/daily?date=` — 당일/전일/당월 통계 + 최근 14일 시리즈
- `GET /api/stats/monthly?year=&month=` — 월별 통계 (전월대비 포함)
- `GET /api/stats/quarterly?year=&quarter=` — 분기별 통계 (전분기대비 포함)
- `GET /api/stats/yearly?year=` — 연도별 통계 (전년대비 포함)
- `GET/POST /api/codes`, `DELETE /api/codes/<id>` — 드랍다운 코드 관리
- `POST /api/import-json` — 엑셀에서 추출한 내역 일괄 등록 (중복 자동 스킵, 신규 코드 자동 추가)

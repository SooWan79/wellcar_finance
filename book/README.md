### 발견된 수정 지점 11건

**치명 (출간 전 필수)**

1. 부록 도구 3·6이 `5-5 「세 가지 시간」`을 참조 — 5-5의 실제 제목은 「후배가 따라오게
   만드는 리더 — 김사부의 12화」. '세 가지 시간'은 편이 아니라 소제목.
2. '여덟 가지 토양'(프롤로그 3회) ↔ '일곱 가지 토양'(부록 2회) 불일치.
3. 목차에 부록(9,504자, 도구 6종) 누락.

**구조 (개정 권장)**

6. 2-7이 장 마무리 편인데 35편 중 최소(2,503자).

**다듬기**

## 분석 스크립트

원고를 고친 뒤 다시 돌려 수치를 갱신할 수 있습니다.

```bash
python extract.py 원고.docx          # .docx → manuscript_raw.txt
python analyze2.py                   # 편별 분량·구성요소·장별 합계
python chk.py                        # 편별 템플릿 준수 (제사/고전카드/Reflection)
python motif.py                       # 모티프 반복 분포
python xref.py                        # 상호참조 ↔ 실제 편 제목 대조
```

| 파일 | 역할 |
|---|---|
| `extract.py` | .docx 파싱 (스타일명 + 표 보존) |
| `analyze2.py` | 편 경계 인식 후 분량·표·성찰·고전 유무 집계 |
| `chk.py` | 35편 템플릿 요소 준수 검사 |
| `motif.py` | 반복 모티프의 등장 위치 추적 |
| `xref.py` | `x-y 「제목」` 형식 상호참조 검증 |
